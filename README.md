# AI Codex Samples

## Personal Management ASP.NET Core App

This repository includes a complete ASP.NET Core MVC sample named **PersonalManagementApp** that can be opened directly in Visual Studio 2026.

### Features
- Dashboard with task and contact metrics.
- Task management (create, edit, delete, mark complete).
- Contact management (create, edit, delete).
- In-memory service with starter sample data.

### Open in Visual Studio 2026
1. Open `PersonalManagementApp.sln`.
2. Set `PersonalManagementApp` as startup project.
3. Press **F5**.

### Run from command line
```bash
cd PersonalManagementApp
dotnet run
```
